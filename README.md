# CodeQuick: learn developer fundamentals in 3 minutes a day

**CodeQuick** is a small, free learning game for developers who already know how to code.
It teaches the things you still need to understand when AI writes the code: code basics, data structures, algorithms, how code runs, OOP, clean code, testing, Git, databases, web, networking, frontend, async, debugging, architecture, distributed systems, DevOps, security and AI-assisted development.
It also explains the business domains IT serves (ERP, sales, inventory, manufacturing, logistics, accounting, payments, HR, healthcare, education, booking) in English + Vietnamese.

### 👉 Play now: **https://mjnamjkaze.github.io/CodeQuick/**

No account, no login, no ads. Your progress stays in your own browser.

---

## How it works

- 📖 **Short lessons**: 2–5 minutes each. Simple English (business domains also in Vietnamese), a small diagram, a real-world example, and one 💡 line to remember.
- ✅ **Quizzes after every lesson**: scenario questions, code reading, debugging and performance puzzles. Each answer comes with a short explanation.
- ⚡ **Daily 5**: five questions from five topics, about 3 minutes, worth a +100 XP bonus.
- 🔁 **Practice my mistakes**: questions you answer wrong come back until you answer them right.
- 🎲 **Random quiz**: questions from all topics, with more of your weak topics.
- 📄 **Cheat sheets**: one compact page per topic, useful even without the lessons.
- 🔥 **XP, levels and streaks**: from *Curious* up to *System Thinker*.
